# Quagmare コミュニティ翻訳

[English](./README.md) | [简体中文](./README.zh-CN.md) | **日本語**

ゲーム **Quagmare v0.15_h** は [dekainu](https://twpf.jp/Liquid_oog) が制作し、[Kanisuko](https://github.com/Kanisuko) が翻訳を管理しています

## インストール

1. 下の一覧から必要な言語の JSON をダウンロードします
2. Quagmare 翻訳ツールを開き、ゲームのフォルダーまたはその中の `Game` フォルダーを選択します
3. **翻訳ファイルを読み込む** を選び、JSON ファイルを読み込みます
4. ゲームを終了し、**翻訳ファイルを適用** を選択します。ツールがゲームのデータとスクリプトに訳文を書き込み、自動でバックアップを作成します
5. ゲームを起動します

直接書き込んだ翻訳を更新する場合は、**先に古いバックアップを復元**してから新しいファイルを読み込んで適用してください。JSON を `Game/data` に置くだけではインストール**できません**
