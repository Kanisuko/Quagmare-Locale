# 翻译注意事项

[English](./TranslationNotes.md) | **简体中文** | [日本語](./TranslationNotes.ja-JP.md)

1. 建议结合 `file`、`context`、前后台词及角色语气理解原文
2. 除非必要否则不建议添加原文没有的内容
3. **强烈建议**角色姓名统一为罗马音，例如（Purei、Rahabu、Meo、Doba）

## 注意需要保留的特殊字符

- `%1`、`%2`、`%3`、`${...}` 等动态占位符
- `\n[1]`、`\V[1]`、`\I[1]`、`\C[0]`、`\MP[...]`、`\MPD[...]` 等控制符及参数
- 真实换行和 JSON 转义
- `<リアクション: ...>` 中的完整日文标识，以及选项末尾 `if(...)` / `en(...)` 条件
- 数值、倍率、持续回合、目标范围、ID 与脚本逻辑

## 状态与原作问题

`untranslated` 表示未翻译，`translated` 表示已翻译未复核，`reviewed` 表示已复核，`needs-review` 表示待核实，`reference` 仅用于原文目录 （当然，你直接写已复核也可以...但是如果可以的话，即使让AI帮忙复核一遍也能）
