# 翻訳上の注意

[English](./TranslationNotes.md) | [简体中文](./TranslationNotes.zh-CN.md) | **日本語**

1. `file`、`context`、前後の台詞、キャラクターの口調を参考に原文を理解してください
2. 必要な場合を除き、原文にない内容を追加しないことをおすすめします
3. **強く推奨：**キャラクター名はローマ字で統一してください（Purei、Rahabu、Meo、Doba など）

## 保持する必要がある特殊文字

- `%1`、`%2`、`%3`、`${...}` などの動的プレースホルダー
- `\n[1]`、`\V[1]`、`\I[1]`、`\C[0]`、`\MP[...]`、`\MPD[...]` などの制御文字と引数
- 実際の改行と JSON のエスケープ
- `<リアクション: ...>` 内の日本語識別子全体、および選択肢末尾の `if(...)` / `en(...)` 条件
- 数値、倍率、継続ターン数、対象範囲、ID、スクリプトの処理

## ステータスと原作の問題

`untranslated` は未翻訳、`translated` は翻訳済み・未確認、`reviewed` は確認済み、`needs-review` は要確認を表します。`reference` は原文カタログ専用です（直接確認済みにしても構いませんが、できれば AI に一度確認してもらうだけでもおすすめします）
