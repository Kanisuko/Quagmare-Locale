# Quagmare 社区翻译

[English](./README.md) | **简体中文** | [日本語](./README.ja-JP.md)

游戏 **Quagmare v0.15_h** 由 [dekainu](https://twpf.jp/Liquid_oog) 创作，本地化由 [Kanisuko](https://github.com/Kanisuko) 维护

## 安装

1. 下载下表中需要的语言 JSON
2. 打开 Quagmare 翻译工具，选择游戏目录或其中的 `Game` 文件夹
3. 点击 **导入译文**，导入 JSON 文件
4. 关闭游戏，点击 **应用翻译文件**。工具会自动把译文写入游戏数据与脚本，并自动备份
5. 启动游戏

在更新已直接安装的译文前，**先恢复旧备份**，再导入并写回新版，只把 JSON 放入 `Game/data` **不会**完成安装
