# Quagmare Community Localization

**English** | [简体中文](./README.zh-CN.md) | [日本語](./README.ja-JP.md)

Community localization of **Quagmare v0.15_h**, created by [dekainu](https://twpf.jp/Liquid_oog) and maintained by [Kanisuko](https://github.com/Kanisuko)

## Installing

1. Download the locale JSON you need from the table below
2. Open Quagmare Translation Tool and select the game directory or its `Game` folder
3. Choose **Import translation files** and import the JSON
4. Close the game and choose **Apply translation files**. The tool writes the translations into the game's data and scripts and creates a backup automatically
5. Start the game

Before updating a directly installed translation, **restore the old backup first**, then import and apply the new version. Simply placing the JSON in `Game/data` **does not** install it

## Contributing

Read the [Contribution Guidelines](./docs/CONTRIBUTING.md) and [Translation Notes](./docs/TranslationNotes.md). Preserve source text, stable IDs and source locations; character names use romaji. Community JSON can be converted to and from the tool's Translator++ `.trans` projects
